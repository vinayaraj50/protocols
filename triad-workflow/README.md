# 🎭 The Triad Workflow: Codex & Antigravity's Tag Team

Welcome to the **Triad Workflow** folder! 

This is the **original backup** of the Triad workflow, where two AI giants argue over your code until it's absolutely perfect. The Triad Workflow is a `Generator → Critic → Verifier` pipeline that leverages the raw coding muscle of **Codex CLI** and the architectural wisdom of **Antigravity**.

## 🧠 How It Works (The Original Run)

1. **Phase 0 (Brief):** Antigravity takes your prompt and strictly formats it into a TASK_BRIEF.md with boundaries and scope.
2. **Phase 1 (Generator):** Codex searches the web, flexes its 2026 muscles, and writes the absolute smallest correct change diff. No overengineering allowed.
3. **Phase 2 (Critic):** Antigravity steps back in. It runs a `last30days` web search and audits Codex's work against the latest best practices and checks for scope drift.
4. **Phase 3 (Reviser):** Only runs if the Critic hated the code. Codex cries a little, then simplifies it.
5. **Phase 4 (Verifier):** Antigravity steps in one last time, judges the simplicity on a scale of 1-10, and either ships it or sends it back to Codex.
6. **Phase 5 (Human Gate):** You, the boss, look at a pretty summary table and type **`Y`** to deploy.

## 📜 Why is this backed up?

This folder preserves the *original* state of the Triad workflow (before any token-saving optimizations) for protocol and ledger tracking. Dive into `triad.md` to see the magic under the hood! Note that this file specifies Antigravity doing the heavy lifting for review and verification phases!
