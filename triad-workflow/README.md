# 🎭 The Triad Workflow: Codex & Antigravity's Tag Team

Welcome to the **Triad Workflow** folder! 

Ever wanted to see two AI giants argue over your code until it's absolutely perfect? Well, you're in the right place. The Triad Workflow is a `Generator → Critic → Verifier` pipeline that leverages the raw coding muscle of **Codex CLI** and the architectural wisdom of **Antigravity**.

## 🧠 How It Works (The TL;DR)

1. **Phase 0 (Brief):** You drop a tiny prompt. Codex expands it into a beefy, structured Task Brief. *(Oh, and if there's UI involved? Antigravity puts on its reading glasses and handles the browser).*
2. **Phase 1 (Generator):** Codex searches the web, flexes its 2026 muscles, and writes the absolute smallest correct change. No overengineering allowed.
3. **Phase 2 (Critic):** Codex clocks out, puts on a fake mustache, and clocks back in as a **Ruthless Reviewer**. It audits its own work against the latest best practices.
4. **Phase 3 (Reviser):** Only runs if the Critic hated the code. Codex cries a little, then simplifies it.
5. **Phase 4 (Verifier):** Antigravity steps in, judges the simplicity on a scale of 1-10, and either ships it or sends it back.
6. **Phase 5 (Human Gate):** You, the boss, look at a pretty summary table and type **`Y`** to deploy.

## 📜 Why is it here?

Because code is cheap, but *good* code is expensive. The Triad ensures that we find the absolute simplest, most elegant solution without bloated abstractions. Oh, and shifting the heavy lifting to Codex saves you tons of Orchestrator tokens. *You're welcome.*

Dive into `triad.md` to see the magic under the hood!
